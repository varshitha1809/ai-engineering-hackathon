# PHISHDNA AI — AI-driven phishing & social-engineering detection

Evidence-driven email-threat investigation: a trained text classifier plus deterministic identity, URL, attachment,
hidden-content and AI-assistant-injection forensics, fused into an explainable verdict; evidence-linked attack
reconstruction; campaign correlation from shared indicators; and a robustness lab that measures the pipeline on
labelled, evasive variants. Local-first — no paid service or API key required.

* Architecture: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) · ML: [ML_PIPELINE.md](ML_PIPELINE.md) · SVM: [svm.md](svm.md)
* Security & limitations: [docs/SECURITY.md](docs/SECURITY.md) · Build log & requirement checklist: [IMPLEMENTATION_LOG.md](IMPLEMENTATION_LOG.md)

## Requirements
Python 3.11, Node 20+ (tested 24.15), ~2 GB free disk for datasets. Windows, macOS or Linux.

## Setup
```bash
pip install -r requirements.txt
cd frontend && npm install && cd ..
cp .env.example .env            # optional; defaults work without it
```

## Data, training and evaluation (already done in this repo's build; re-run to reproduce)
```bash
python scripts/download_datasets.py --supplementary   # MeAJOR parquet (+CSV fallback) and supplementary CSVs, MD5-verified
python scripts/preprocess_dataset.py                  # profile, dedupe (exact + MinHash), group-aware 70/15/15 split
python scripts/train_model.py                         # LR vs linear SVM on two pools, select on validation, save artifact
python scripts/evaluate_model.py                      # held-out test metrics -> models/evaluation_latest.json
python scripts/build_benchmark.py                     # robustness-lab fixtures (synthetic, sanitised)
python scripts/build_demo_fixtures.py                 # local demo sample set
```
The trained artifact is in `models/` (`phishdna_text_model.joblib` + `model_metadata.json` with SHA-256). Raw data
(`data/raw/`) and the processed corpus are git-ignored and regenerated by the commands above.

## Run
**Complete stack, one process** (FastAPI serves the API and the built frontend):
```bash
cd frontend && npm run build && cd ..
python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
# open http://127.0.0.1:8000  (landing)  ·  http://127.0.0.1:8000/app  (analyst app)  ·  /docs (OpenAPI)
```
**Development** (hot reload; Vite proxies `/api` to port 8000):
```bash
python -m uvicorn backend.app.main:app --reload --port 8000
cd frontend && npm run dev        # http://localhost:5173
```

## 3-minute demo
1. **Analyze** → paste a zero-link vendor bank-change email with headers → *Likely phishing*; open **Evidence explorer** and
   **Attack reconstruction** (observed vs inferred, verification steps).
2. **Analyze → Upload .eml** → `data/fixtures/demo/11-hidden-instr.eml` → *AI-assistant manipulation suspected*; the
   "Hidden content & AI view" tab shows the hidden instruction as inert evidence.
3. **Analyze → Local sample set → Import** → **Campaign intelligence**: shared URL, shared Reply-To (low-and-slow), same
   impersonated CEO profile, shared attachment hash; click an edge to see its evidence.
4. **Robustness lab → Run benchmark** → baseline vs hybrid, confusion matrices, failures tab, limitations.
5. **Cases** → report / quarantine (local) / note → status and audit trail persist. **Settings → Local IOC store** → mark
   `secure-docs-portal.test` malicious → retained messages are re-scored with before/after verdicts.

## Deployment notes
Single-host: build the frontend, run uvicorn behind a reverse proxy (TLS), set `PHISHDNA_API_KEY` and
`VITE_API_KEY` (build-time) to require a key, set `PHISHDNA_ORG_DOMAINS` and `PHISHDNA_TRUSTED_AUTHSERV_IDS` for your
environment, and `PHISHDNA_RETAIN_RAW=false` if raw content must not be stored. External lookups stay off unless
`PHISHDNA_ENABLE_EXTERNAL_LOOKUPS=true` and `VIRUSTOTAL_API_KEY` are set. Mailbox/SIEM integrations are not included;
all response actions are local records.
